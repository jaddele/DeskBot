# DeskBot 桌面机器人

本项目使用 ESP32-WROOM-32、双舵机、两个红外避障模块、TTP223 触摸模块和 128×64 SSD1306 OLED。程序采用非阻塞状态机：传感器只提供输入，`bot_core` 统一决定动作和表情，硬件模块只执行命令。

## 最终接线

| 器件 | 信号 | ESP32 引脚 | 电源与注意事项 |
|---|---|---:|---|
| 水平 yaw 舵机 | 信号线 | GPIO 13 | 外接 5V，和 ESP32 共地 |
| 俯仰 pitch 舵机 | 信号线 | GPIO 12 | 外接 5V，共地；GPIO12 不接上拉或下拉 |
| TTP223 | SIG | GPIO 4 | 3.3V；默认 HIGH 表示触摸 |
| 左红外 | OUT | GPIO 5 | 3.3V；LOW 表示检测到障碍物 |
| 右红外 | OUT | GPIO 18 | 3.3V；LOW 表示检测到障碍物 |
| SSD1306 OLED | SDA | GPIO 21 | 3.3V，I²C 地址 0x3C |
| SSD1306 OLED | SCL | GPIO 22 | 3.3V |
| 无源蜂鸣器（预留） | I/O | GPIO 26 | 当前程序未启用 |
| WS2812 眼睛（预留） | DIN | GPIO 27 | 当前程序未启用 |

## 互动行为

- 左红外有效：向左转头、抬头到 120°、显示开心眼。
- 右红外有效：向右转头、抬头到 120°、显示开心眼。
- 两侧同时有效：水平停止、继续抬头、显示默认眼睛。
- 红外目标消失：原地保持并显示疑惑；3 秒后两轴平滑回到 90°。
- 触摸稳定 100 ms：立即停止水平动作、抬头并显示疑惑。
- 持续触摸满 800 ms：改为爱心眼；一次按住只产生一次长按事件。
- 松手后保持当前触摸表情并等待新红外操作；3 秒无新操作则归中。
- 触摸后必须先看到左右红外都恢复无障碍，后续新遮挡才可接手，旧遮挡不会打断归中。

## 代码结构与调参

- `src/main.cpp`：只负责调用初始化和周期更新。
- `src/bot_core.*`：组合输入、状态机、舵机命令和 OLED 刷新。
- `src/bot_behavior.*`：可在电脑上测试的行为优先级与计时逻辑。
- `src/input_filters.*`：触摸消抖、长按事件和红外多数表决。
- `src/servo_motion.*`：与硬件无关的角度目标和缓动。
- `src/hardware/`：ESP32 引脚、Servo、GPIO 和 OLED 适配。
- `src/robot_config.h`：所有引脚、电平、角度和时间参数。实机调整应优先修改这里。

若 TTP223 实测为 LOW 有效，把 `TouchActiveHigh` 改为 `false`。如果机械结构需要修改抬头角度，调整 `RaisedHeadAngle`，并保持在 `VerticalMinimumAngle` 到 `VerticalMaximumAngle` 的安全范围内。

## 实机验收顺序

1. 不装舵机摇臂上电，确认两个舵机先到 90°，GPIO12 不影响启动。
2. 装回摇臂，分别遮挡左右红外，确认 yaw 方向与机械结构一致；若相反，应交换软件中的左右动作映射，不要强扭摇臂。
3. 确认 pitch 从 90° 到 120°确实抬头且不顶住结构。
4. 短触后检查疑惑眼、水平立即停止和抬头；长触 800 ms 后检查爱心眼。
5. 保持旧红外遮挡并松开触摸，确认它不会立即接手；移开后再次遮挡，确认跟随恢复。
6. 测试红外丢失与触摸松手后的 3 秒归中，并观察舵机是否有堵转、抖动或过热。

自动测试和构建不能代替以上实机检查，尤其是舵机方向、机械限位和 TTP223 实际输出电平。
